# 公司 OCR 真实联调记录

日期：2026-11-03。此记录更新此前仅离线验证、缺少上传配置的结论。

## 本轮解决的问题

1. **本地图片无法交给 URL 型接口。** 使用用户授权的上海 `ocr-phy` 桶上传，生成临时签名链接，按题方 `file/task/callBack/taskType` 协议调用公司 OCR；终态响应取得后清理对象。无需本地视觉模型或额外视觉 API。
2. **接口成功但项目拿不到内容。** 公司实际返回 `data.list` 和 `chargeList`，原解析器只读取通用文本字段。现已适配真实结构，保留原始响应与字段路径；不把接口提取结果称为图片逐字转录。
3. **旧凭据返回 403。** 新凭据已实际完成上传、OCR 拉取和清理。错误信息仅保存状态、错误码和安全上下文，不显示密钥。配置文件凭据与环境变量凭据不可混配。
4. **EML 推广图阻塞整封邮件。** 已人工查看样例推广横幅，按精确 SHA256 登记非账单素材核验理由，仅限邮件附件范围；文件和跳过记录仍归档。同名而内容不同的图片、未知图片和独立上传图片继续识别，不能因空响应自动忽略。
5. **缺失币种规则冲突。** 按用户确认，缺失币种保持未知并人工核对，不默认补 USD。默认 AR 是独立的业务方向规则，不用于推断币种。

## 回归及使用

完整 `tests/` 回归：**276 passed, 1 warning**。警告为已有 PyPDF2 弃用提示。测试不调用真实服务，真实联调证据单独列在上表；没有写入真实 SQL 账本。

所有本轮受控输出、解析档案、备份及测试临时目录均位于项目 D 盘；使用 `-B`、禁用 pytest 缓存与插件自动发现，并明确设置 TEMP/TMP/TMPDIR。没有清理 C 盘已有文件。

必须停止并重新启动 Streamlit 进程，再生成新预览，使配置、解析器和核验素材清单生效。仅刷新浏览器不会替换进程启动时已加载的环境变量。缺币种的费用应显示待复核，而不是自动入账。

当前配置说明见 [公司 OCR 配置与输入限制](公司OCR配置与输入限制.md)。

新 OSS 凭据保存在 Git 忽略的 `.secrets/oss-credentials.csv`，`.env` 中对应两项值已清空并保留 CSV 路径。现有 `.env` 已被仓库跟踪，不能用“加入忽略规则”当作脱离版本控制的证明。本轮没有操作 Git 暂存区或改写历史。
