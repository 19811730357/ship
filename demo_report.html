📊 项目完成状态

✅ 已实现功能

  • 文件解析器 - 支持 EML、PDF、Word、Excel、TXT 格式
  • LangChain Agent - 使用 LCEL 链式调用 (prompt | llm | parser)
  • 完整工作流 - 解析 → 决策 → 验证 → 冲突解决
  • 前端界面 - Streamlit 文件上传和结果展示
  • OCR 集成 - 代码已实现（需要配置 API）

⚠️ 使用说明

  • 模拟模式：无需配置，使用预设场景演示（当前报告）
  • 真实模式：需要在 .env 配置 DASHSCOPE_API_KEY
  • OCR 功能：需要文件 URL（可选配置 OSS 上传）
  • 数据存储：当前使用 JSON 文件，无需数据库

🚀 启动方式

conda activate ship_env
streamlit run app.py
查看详细结果：
- output/update/ - 明确更新场景
- output/ambiguous/ - 歧义场景
- output/create/ - 新增场景
- output/conditional/ - 条件收费场景

每个目录包含 processing_results.json、ledger_snapshot.json、run_report.json
